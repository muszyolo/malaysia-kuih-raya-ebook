Overview

Kuih raya in Malaysia is both festive and regional. Some sweets are famous nationwide, while others are deeply tied to a state, a royal kitchen, a local ethnic community, or a family tradition kept alive during Aidilfitri.

traditional kuih Aidilfitri table ideas state-based browsing recipe links photo-backed cards

This version works well as a public reading page, a starter ebook for your repository, or a foundation for a larger cookbook later. If you want, you can keep adding your own photos, family notes, downloadable PDF and EPUB versions, or fully original recipes in the same docs folder.

Key takeaway The page is already publishable as a GitHub Pages ebook, but it is also structured so you can grow it into a much bigger Malaysian kuih raya archive.

How to Use This Ebook

Suggested workflow for this repository:

  • Keep this page as the public-facing state directory.
  • Add your own notes under each state if your family or community has different kuih associations.
  • Replace any outbound recipe link with your own original recipe page later if you want a fully owned cookbook.
  • Swap the representative images for your own archive over time.

Source and Image Notes

The starter links in this ebook were curated mainly from RASA, Penang Travel Tips, Crisp of Life, MySabah, and MyResipi. They were chosen because they provide either a recipe, a state or community connection, or both.

The photos are pulled from Wikimedia Commons so the page has clearer reuse footing than random hotlinked food images. Where an exact state-matched open image was not easy to verify, I used a clearly labeled representative festive kuih photo instead.

This means the page is best understood as a practical, editable directory rather than a definitive academic source on origin claims. If you want a stricter version later, we can add source citations, publication dates, and a more formal provenance note for every state.

Next upgrade idea The best next step is to replace the representative photos with your own archive over time so the ebook becomes uniquely yours instead of only linking outward.
